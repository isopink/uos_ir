# 칠판 읽어주는 로봇

> 칠판이 잘 안 보이는 학생을 위해, 로봇이 칠판이 잘 보이는 위치로 가서 칠판을 읽고, 강의실 안의 화면에 정리해서 보여준다.

## 1. 개요

와플파이가 강의실 지도에서 칠판 위치를 알고, **칠판을 정면에서 반사 없이 볼 수 있는 지점으로 스스로 이동**해 촬영한다. 찍은 사진은 원근 보정으로 정면 사진으로 바꾸고, 숫자(출석 코드 등)를 인식해 크게 보여주며, 칠판이 지워지기 전에 자동으로 기록을 남긴다.

- **실용성**: 뒷자리·저시력 학생의 칠판 가독성 문제, 지워지면 사라지는 필기 문제 해결
- **로봇이 필요한 이유**: 고정 카메라는 사각지대·반사·각도 문제가 있음 → 로봇이 **좋은 촬영 위치를 찾아 이동**하는 것이 핵심
- **수업 연결**: 원근 보정(동차좌표, Homography), 지도 기반 위치 추정·주행

## 2. 해결하려는 문제

- 뒷자리, 기둥 뒤에서는 칠판이 잘 안 보인다 (저시력 학생은 더 심함)
- 분필·마커 글씨는 조명 반사와 흐린 글씨 때문에 읽기 어렵다
- 칠판 필기는 지우면 다시 볼 수 없다

## 3. 사용 원칙

- 인식 결과는 **로봇 화면 또는 강의실 프로젝터 등 강의실 안에서만** 보여준다
- 외부 전송 기능은 만들지 않는다 (출석 코드가 강의실 밖으로 나가면 대리 출석 도구가 됨)

## 4. 시나리오

```
수업 시작
↓
로봇이 지도에서 칠판 위치 확인 → 정면·반사 적은 촬영 지점으로 이동
↓
카메라로 칠판 촬영 (반사가 심하면 각도를 바꿔 재촬영)
↓
칠판 네 모서리 검출 → 원근 보정으로 정면 사진 생성
↓
숫자 인식 → "출석 코드: 4827" 처럼 화면에 크게 표시
↓
칠판 변화 감지 (새로 씀 / 지워짐) → 지워지기 전 자동 촬영
↓
수업 종료 시 "오늘의 칠판 기록" 정리
```

## 5. 시스템 구성

| 모듈 | 입력 | 출력 | 사용 기술 |
|------|------|------|-----------|
| 지도 / 위치 추정 | LiDAR, 오도메트리 | 강의실 지도, 로봇 pose | SLAM, AMCL (0단계 결과 재사용) |
| 촬영 위치 선정 | 지도, 칠판 위치 | 목표 지점 | 칠판 정면·거리·반사 기준 점수 |
| 원근 보정 | 칠판 사진 | 정면 사진 | 모서리 검출 + Homography |
| 숫자 인식 | 정면 사진 | 숫자 문자열 | 경량 숫자 인식 모델 (직접 학습) |
| 변화 감지 | 연속 사진 | 새로 씀 / 지워짐 이벤트 | 이전 사진과 비교 |
| 표시 / 기록 | 인식 결과, 사진 | 화면 표시, 기록 파일 | 로컬 화면 / 강의실 내 표시 |

## 6. 개발 단계

| 단계 | 목표 | 산출물 |
|------|------|--------|
| 0 | 강의실(또는 실습실) 지도 생성 | 지도 파일 |
| 1 | 고정 위치에서 칠판 촬영 + 원근 보정 | 정면 보정 사진 |
| 2 | 숫자 인식 (출석 코드) | 인식 정확도 측정 |
| 3 | 촬영 위치 자동 선정 + 이동 | 이동 후 촬영 데모 |
| 4 | 변화 감지 + 자동 기록 | 칠판 기록 정리 |
| 5 | 안정화 / 평가 | 데모, 평가 결과 |

## 7. 평가 지표

- 숫자 인식 정확도 (거리·각도별)
- 원근 보정 전/후 인식률 비교
- 고정 위치 vs 로봇이 고른 위치의 인식률 비교 (로봇 이동의 효과)
- 변화 감지 누락·오탐 횟수

## 8. 데모 시나리오

1. 칠판(화이트보드)에 "출석 코드 4827"과 수식 몇 줄을 적는다
2. 로봇이 촬영 위치로 이동 → 화면에 정면 보정 사진 + 인식 결과 표시
3. 일부를 지우고 새로 쓰면 → 기록이 자동으로 추가됨

## 9. 필요 장비

- TurtleBot3 Waffle Pi (LiDAR, 오도메트리)
- 카메라: C920 / RealSense D455F / Pi 카메라 중 선택 (미정)
- 영상 처리: Jetson Xavier NX (로봇 탑재 여부 미정)

## 10. 위험 요소 및 대응

| 위험 | 대응 |
|------|------|
| 손글씨 한글 인식이 어려움 | 숫자 인식을 핵심으로, 나머지는 사진 기록만 |
| 칠판 반사, 흐린 분필 | 각도를 바꿔 여러 장 촬영, 데모는 화이트보드 + 진한 마커 |
| OCR 라이브러리 설치가 Jetson 환경을 깰 위험 (opencv-python 동반 설치) | PaddleOCR 등 무거운 라이브러리 대신 직접 학습한 작은 숫자 인식 모델 사용, 설치 전 의존성 확인 |
| Jetson 미탑재 시 영상 전송 지연 | 정지 상태에서만 촬영하므로 실시간성 요구가 낮음 → 사진 단위 전송으로 충분 |

## 11. 확장 아이디어

- 로봇 사진사와 통합: 사람을 찍으면 단체사진, 칠판을 찍으면 필기 기록 ("좋은 장면이 나오도록 로봇이 자리를 옮긴다"는 핵심이 같음)
