# 줄 대신 서주는 로봇

> 학식 줄에 로봇만 세워두고 자리를 비움 → 차례가 다가오면 "앞에 3명 남았어요!" 알림

## 1. 개요

와플파이가 사용자 대신 줄에 서서 **LiDAR로 앞사람과의 간격을 유지하며 줄이 줄어드는 만큼 전진**한다. 앞에 남은 사람 수를 세고 대기 시간을 예측해, 차례가 가까워지면 사용자에게 알린다.

- **실용성**: 학식·행정실·행사 줄에서 기다리는 시간을 다른 일에 쓸 수 있음
- **로봇이 필요한 이유**: 줄은 계속 움직이므로 고정 장치로는 불가능 → 로봇이 **줄을 따라 이동하며 자리를 지키는 것**이 핵심
- **센서 부담이 적음**: 핵심 기능은 LiDAR만으로 동작 (카메라·Jetson 탑재 여부의 영향이 적음)
- **수업 연결**: Sensor Models(LiDAR 빔 모델, 노이즈), Kalman Filter(앞사람 위치 추적), 확률적 판단(사람 / 사물 구분, 대기 시간 예측)

## 2. 해결하려는 문제

- 점심시간 학식, 행정 창구, 행사 입장 줄에서 수십 분씩 서 있어야 한다
- 친구에게 자리를 맡기는 것은 친구도 같이 기다려야 함
- 번호표 시스템이 없는 곳이 많다

## 3. 사용 원칙

- 로봇이 차지하는 자리는 **사람 한 명분**으로 한정 (여러 자리 맡기 금지)
- 줄 끝에 정상적으로 합류하며 새치기하지 않는다
- 사용자가 차례 전에 돌아와 교대하는 것을 전제로 함

## 4. 시나리오

```
사용자가 로봇을 줄 맨 뒤에 세우고 시작
↓
LiDAR 스캔 → 점들을 묶어 "사람 덩어리" 검출 → 앞사람 추적
↓
앞사람이 전진하면 간격(약 0.8 m)을 유지하며 따라 전진, 멈추면 정지
↓
줄 앞쪽 사람 수 세기 + 전진 속도로 남은 대기 시간 예측
↓
"앞에 3명 남았어요 / 약 2분" → 사용자에게 알림 (웹페이지)
↓
사용자 도착 → 교대 버튼 → 로봇은 줄에서 빠져 대기 위치로 복귀
```

## 5. 시스템 구성

| 모듈 | 입력 | 출력 | 사용 기술 |
|------|------|------|-----------|
| 사람 검출 | LiDAR 스캔 | 사람 후보 위치 목록 | 점 묶기(클러스터링), 크기·모양 필터 |
| 앞사람 추적 | 사람 후보, 오도메트리 | 앞사람 위치·속도 | Kalman Filter |
| 간격 유지 제어 | 앞사람 위치 | 속도 명령 | 거리 오차 기반 제어 + 안전 정지 |
| 줄 인식 / 인원 세기 | 사람 후보 목록 | 줄 모양, 앞 인원 수 | 줄 방향 직선 근사, 일정 간격 이어진 사람만 줄로 인정 |
| 대기 시간 예측 | 전진 기록 | 남은 시간 | 평균 전진 속도 / 인원당 처리 시간 추정 |
| 알림 | 인원 수, 예상 시간 | 웹페이지 표시 | 간단한 웹 서버 (같은 네트워크) |

## 6. 개발 단계

| 단계 | 목표 | 산출물 |
|------|------|--------|
| 0 | 로봇 연결, 텔레옵, LiDAR 데이터 확인 | `/scan` 확인 |
| 1 | LiDAR로 앞의 가장 가까운 물체 따라 전진·정지 | 간격 유지 데모 |
| 2 | 사람 덩어리 검출 + Kalman Filter 추적 | 추적 시각화 (RViz) |
| 3 | 줄 인식 + 앞 인원 세기 + 대기 시간 예측 | 줄 인원 표시 |
| 4 | 웹 알림 + 교대 기능 | 휴대폰 알림 데모 |
| 5 | 안정화 / 평가 | 데모, 평가 결과 |

## 7. 평가 지표

- 간격 유지 오차 (목표 0.8 m 대비)
- 앞 인원 수 세기 정확도
- 대기 시간 예측 오차 (예측 vs 실제)
- 끼어들기·오정지 횟수 (줄 옆을 지나가는 사람에 대한 반응)

## 8. 데모 시나리오

1. 교수님 포함 4~5명이 한 줄로 선다, 로봇을 맨 뒤에 세우고 시작
2. 맨 앞사람부터 한 명씩 빠짐 → 로봇이 간격을 유지하며 전진
3. 줄 옆으로 다른 사람이 지나가도 반응하지 않음 (줄 인식)
4. 화면에 "앞에 2명 남았어요 / 약 1분" 표시 → 사용자가 와서 교대

## 9. 필요 장비

- TurtleBot3 Waffle Pi (LiDAR, 오도메트리) — 핵심
- 알림용 노트북/휴대폰 (같은 네트워크의 웹페이지)
- (선택) 카메라: 사람 / 사물 구분 보조

## 10. 위험 요소 및 대응

| 위험 | 대응 |
|------|------|
| LiDAR 높이에서 사람 다리가 2개로 보이거나 가방 등 사물과 구분이 어려움 | 다리 2개를 한 사람으로 묶는 규칙, 일정 시간 움직임이 있는 덩어리만 사람으로 인정 |
| 줄이 휘거나 옆사람이 끼어듦 | 줄 방향 직선 근사 + 앞사람 추적 유지, 시연은 직선 줄로 |
| 와플파이 속도가 느림 (최대 약 0.26 m/s) | 줄 전진 속도가 느려 문제 없음 |
| 실제 학식 시연은 불가 | 강의실·실습실에서 사람들로 줄을 재현 |

## 11. 확장 아이디어

- 카메라로 줄 앞쪽 상황(남은 메뉴 등) 촬영 전송
- 여러 줄 중 가장 빨리 줄어드는 줄 추천
