# 말로 물어보는 물건 찾기 로봇

> "아까 본 파란 머그컵 어디 있어?" → 로봇이 기억을 검색해 그 위치로 데려간다.

## 1. 개요

와플파이가 공간을 돌아다니며 **본 물체의 이미지 특징(CLIP 임베딩)과 지도상 위치·관측 시각을 기억**한다. 사용자가 음성으로 물체를 묘사하면, 텍스트-이미지 유사도로 기억 중 가장 그럴듯한 물체를 찾아 해당 위치로 자율 주행한다.

- **창의성**: 정해진 클래스가 아닌 자유로운 묘사("빨간 텀블러", "노트북 옆 충전기")로 검색 (open-vocabulary)
- **멀티모달**: 음성 + 텍스트 + 이미지 + LiDAR
- **완성도**: 지도 작성·위치 추정·주행은 검증된 부품을 사용하고, 핵심 기여는 "물체 기억 + 검색" 모듈에 집중

## 2. 동기

- 물건을 어디 뒀는지 잊는 일상 문제를 로봇의 공간 기억으로 해결
- 기존 객체 검출(YOLO)은 학습된 클래스만 인식 → 실제 생활 속 물체 묘사를 다루기 어려움
- 수업에서 배우는 확률적 로보틱스(Occupancy Grid, 베이즈 업데이트, 위치 추정)를 "물체 기억"으로 확장

## 3. 시스템 구성

```
[와플파이 (Raspberry Pi)]                       [Jetson Xavier NX]
 LiDAR ──────────┐                              ┌─ SLAM / 위치 추정 (지도 + 로봇 pose)
 카메라 ─────────┼──── ROS 2 네트워크 ────────▶ ├─ 물체 검출 (YOLO, TensorRT)
 오도메트리 ─────┘                              ├─ CLIP 임베딩 추출
 모터 제어 ◀──────────────────────────────────── ├─ 물체 기억 DB (위치·임베딩·시각·신뢰도)
                                                ├─ 음성 인식 (Whisper) ◀── USB 마이크
                                                └─ 질의 → 목표 위치 → 경로 계획
```

### 모듈별 역할

| 모듈 | 입력 | 출력 | 사용 기술 |
|------|------|------|-----------|
| 지도 작성 / 위치 추정 | LiDAR, 오도메트리 | Occupancy Grid 지도, 로봇 pose | SLAM, Particle Filter (AMCL) |
| 물체 검출 | 카메라 영상 | 물체 bounding box | YOLO (경량, TensorRT) |
| 물체 위치 추정 | bbox, LiDAR, 로봇 pose | 지도 좌표상 물체 위치 | 카메라-LiDAR 캘리브레이션, 좌표 변환 |
| 물체 기억 | 물체 crop, 위치, 시각 | 기억 DB | CLIP 임베딩, 베이즈 업데이트 |
| 음성 질의 | 음성 | 텍스트 | Whisper tiny/base |
| 검색 / 이동 | 텍스트 | 목표 위치 → 주행 | CLIP 텍스트-이미지 유사도, Nav2 |

## 4. 핵심 아이디어: 확률적 물체 기억

물체마다 다음 정보를 저장한다.

- 위치 `(x, y)` 와 불확실성
- CLIP 이미지 임베딩
- 마지막 관측 시각
- 존재 신뢰도 `p`

**업데이트 규칙**
- 같은 물체를 다시 보면: 위치 갱신, 신뢰도 상승
- 그 자리를 봤는데 물체가 없으면: 신뢰도 하락 (물건이 옮겨진 것)
- 시간이 지나면: 신뢰도 점진적 감소 (오래된 기억일수록 불확실)

**검색 점수** = CLIP 유사도 × 존재 신뢰도 → 가장 높은 후보로 이동. 도착 후 실제로 없으면 다음 후보로 이동.

## 5. 수업 내용과의 연결

| 수업 주제 | 프로젝트 적용 |
|-----------|---------------|
| Linear Algebra, Homogeneous Coordinates | 카메라 → 로봇 → 지도 좌표 변환 |
| Probabilistic Robotics | 물체 존재 확률의 베이즈 업데이트 |
| Motion / Sensor Models | 오도메트리 모델, LiDAR·카메라 관측 모델 |
| Occupancy Grid Maps | 기본 지도 + 물체 기억 레이어 |
| Kalman Filter / EKF | 물체 위치 추정 (반복 관측 융합) |
| Particle Filter, SLAM | 지도 작성 및 로봇 위치 추정 |

## 6. 개발 단계 및 일정

| 단계 | 기한 | 목표 | 산출물 |
|------|------|------|--------|
| 0. 환경 구축 | ~10/15 (실습완료 보고서) | ROS 2 기초 학습(TurtleBot3 튜토리얼), 와플파이-Jetson ROS 2 연결, 텔레옵, LiDAR SLAM 지도 생성 | 지도 이미지, 환경 설정 문서 |
| 1. 물체 검출 + 위치 | ~10/29 (중간보고서) | YOLO TensorRT 실시간 검출, 카메라-LiDAR 캘리브레이션, 물체를 지도에 투영 | 지도 위 물체 표시 데모 |
| 2. CLIP 기억 + 검색 | ~11/12 | 물체 crop → CLIP 임베딩 저장, 텍스트로 검색, 확률적 기억 갱신 | 텍스트 질의 → 위치 반환 |
| 3. 음성 + 자율 이동 | ~11/19 | Whisper 음성 입력, 검색 결과로 Nav2 주행, 실패 시 다음 후보 | 전체 파이프라인 동작 |
| 4. 안정화 / 평가 | ~11/26 (Demo) | 정량 평가, 데모 시나리오 리허설, (선택) 원격 대시보드 | 데모, 평가 결과 |
| 5. 발표 / 보고서 | 12/3, 12/10 | 발표 자료, 결과보고서 | |

### 발전 과정 (보고서에서 보여줄 흐름)

1. 기본: LiDAR 지도 + 로봇 위치
2. YOLO 고정 클래스 물체를 지도에 표시
3. CLIP으로 자유 텍스트 검색 (고정 클래스 → open-vocabulary)
4. 확률적 기억 (오검출 제거, 옮겨진 물체 대응)
5. 음성 질의 + 자율 이동

## 7. 평가 지표

- **검색 성공률**: 질의 N개 중 올바른 물체 위치로 이동한 비율 (Top-1 / Top-3)
- **위치 오차**: 추정 물체 위치와 실제 위치의 거리 (m)
- **YOLO 고정 클래스 vs CLIP 검색** 성공률 비교
- **확률 기억 유무**에 따른 물체 이동 후 성공률 비교
- **시스템 자원**: FPS, 메모리 사용량, 질의 응답 지연 시간 (`jtop`)

## 8. 데모 시나리오

1. 로봇이 연구실을 한 바퀴 돌며 탐색 (대시보드에 지도와 기억된 물체 표시)
2. 사용자: "파란 머그컵 어디 있어?" → 로봇이 머그컵 앞으로 이동
3. 사용자가 머그컵을 다른 곳으로 옮김
4. 다시 질의 → 기존 위치로 갔다가 없음 확인 → 신뢰도 하락 → 탐색 후 새 위치 갱신
5. 묘사형 질의: "노트북 옆에 있는 검은 충전기" 등

## 9. 필요 장비

- TurtleBot3 Waffle Pi (LiDAR, Pi 카메라, OpenCR) — 사용 확정
- NVIDIA Jetson Xavier NX (ASUS PE1000N) — 수업 제공
- Logitech C920 웹캠 — 수업 제공 (Pi 카메라 대신 사용 검토)
- USB 마이크 (와플파이에는 마이크 없음)
- 테스트용 물체들 (머그컵, 텀블러, 가방 등)

### 소프트웨어 참고

- 수업 제공 환경: PyTorch, OpenCV(CUDA), Conda, GStreamer/RTSP, DeepStream ([ir-guide](https://github.com/intMinsu/ir-guide))
- **ROS 2는 수업 범위 밖**이지만, 와플파이(TurtleBot3) 공식 소프트웨어가 ROS 2 기반이라 LiDAR·오도메트리·모터 제어에 필요 → 자체 학습 필요

## 10. 위험 요소 및 대응

| 위험 | 대응 |
|------|------|
| Jetson 8GB 메모리 부족 (YOLO + CLIP + Whisper 동시 실행) | 경량 모델 + TensorRT/FP16, Whisper는 질의 시에만 로드, CLIP은 검출 시에만 실행 |
| 카메라-LiDAR 캘리브레이션 오차 | 초기에 캘리브레이션 시간 확보, 여러 번 관측해 위치 평균/EKF 융합 |
| Jetson 탑재 방식 (전원, 무게) | 조교 확인. 불가 시 무선 ROS 2 네트워크로 원격 처리 |
| 한국어 음성 인식 정확도 | Whisper 한국어 성능 확인, 부족하면 영어 질의 또는 텍스트 입력 백업 |
| CLIP 검색 오답 | Top-3 후보 순차 방문, 유사도 임계값 설정 |
| ROS 2 학습 부담 (수업 범위 밖) | TurtleBot3 공식 튜토리얼(bringup, SLAM, Navigation)로 초반에 집중 학습, 수업 내용(필터, 지도)은 직접 구현한 모듈로 비교·설명 |
| 와플파이와 Jetson의 ROS 2 버전 불일치 | 와플파이 ROS 2 배포판 확인 후 Jetson에 같은 버전 설치 (필요 시 Docker) |
