# 로봇 사진사

> "다 안 나와요~ 뒤로 갈게요" 하며 뒷걸음질 → 전원이 웃는 순간 찰칵

## 1. 개요

와플파이가 카메라로 사람들의 얼굴을 보면서 **모두가 프레임에 잘 들어오도록 스스로 앞뒤·회전 이동**해 구도를 잡고, 모두 눈을 뜨고 웃는 순간 자동으로 단체사진을 찍는다.

- **실용성**: 단체사진에서 누군가 빠지는 문제, 구도·타이밍(눈 감음, 안 웃음) 맞추기 어려운 문제 해결
- **로봇이 필요한 이유**: 고정 카메라(삼각대)는 인원·위치가 바뀌면 사람이 직접 옮겨야 함 → 로봇이 **좋은 구도가 나오는 위치를 찾아 이동**하는 것이 핵심
- **수업 연결**: 카메라 좌표 ↔ 로봇 좌표 변환, 센서 모델(얼굴 검출 노이즈), 확률적 판단(웃음·눈 뜸 판정)

## 2. 해결하려는 문제

- 단체사진은 찍는 사람 한 명이 항상 빠진다
- 삼각대 + 타이머는 구도 확인이 어렵고, 누가 눈을 감거나 안 웃으면 다시 찍어야 한다
- 인원이 많거나 줄이 길면 카메라를 직접 앞뒤로 옮겨 가며 맞춰야 한다

## 3. 시나리오

```
사용자가 "사진 찍어줘" 시작 (버튼 / 키보드)
↓
카메라로 얼굴 검출 → 인원 수, 각 얼굴 위치·크기 파악
↓
구도 점수 계산 (전원 포함 여부, 화면 가장자리 여유, 중앙 정렬, 얼굴 크기)
↓
점수가 좋아지도록 로봇 이동 (잘리면 뒤로, 너무 작으면 앞으로, 치우치면 회전)
↓
구도 OK → "찍을게요~" 안내
↓
전원 눈 뜸 + 웃음 판정이 일정 시간 유지되는 순간 자동 촬영
↓
사진 저장 / 화면에 결과 표시
```

## 4. 시스템 구성

| 모듈 | 입력 | 출력 | 사용 기술 |
|------|------|------|-----------|
| 얼굴 검출 | 카메라 영상 | 얼굴 bounding box | 경량 얼굴 검출 모델 (Jetson 실시간) |
| 표정 판정 | 얼굴 crop | 웃음 / 눈 뜸 확률 | 경량 분류 모델, 여러 프레임 평균 |
| 구도 평가 | 얼굴 bbox 목록 | 구도 점수, 이동 방향 | 프레임 포함·여백·중앙·크기 기준 점수화 |
| 이동 제어 | 구도 점수, LiDAR | 속도 명령 | 카메라 피드백 제어 + 장애물 안전 정지 |
| 촬영 / 저장 | 영상, 판정 결과 | 사진 파일 | 판정 유지 시간 기반 셔터 |

## 5. 개발 단계

| 단계 | 목표 | 산출물 |
|------|------|--------|
| 0 | 로봇 연결, 텔레옵, 카메라 영상 확인 | 영상 확인 |
| 1 | 얼굴 검출 + 구도 점수 (로봇 고정) | 점수 시각화 |
| 2 | 구도 점수로 로봇 앞뒤·회전 이동 | 자동 구도 맞추기 데모 |
| 3 | 웃음·눈 뜸 판정 + 자동 촬영 | 자동 셔터 데모 |
| 4 | 안정화 / 평가 | 데모, 평가 결과 |

## 6. 평가 지표

- 구도 성공률: 전원이 잘리지 않고 들어온 사진 비율
- 구도 맞추기에 걸린 시간 (인원 수별)
- 자동 촬영 사진 중 눈 감음·안 웃음 비율 (일반 타이머 촬영과 비교)
- 처리 속도: FPS, 메모리 (`jtop`)

## 7. 데모 시나리오

1. 교수님 포함 3~5명이 모인다
2. 로봇 시작 → 너무 가까우면 "다 안 나와요~" 하며 뒤로 이동, 구도가 맞으면 정지
3. 누가 눈을 감거나 안 웃으면 기다림 → 전원 웃는 순간 찰칵
4. 한 명이 추가로 들어오면 다시 구도를 조정

## 8. 필요 장비

- TurtleBot3 Waffle Pi (이동, LiDAR 안전 정지)
- 카메라: C920 / RealSense D455F / Pi 카메라 중 선택 (미정)
- 영상 처리: Jetson Xavier NX (로봇 탑재 여부 미정)
- 안내 음성용 스피커 (선택, 노트북 스피커로 대체 가능)

## 9. 위험 요소 및 대응

| 위험 | 대응 |
|------|------|
| Jetson 미탑재 시 영상 전송 지연 | 로봇 이동을 천천히, 조금씩 → 지연이 있어도 구도 수렴 가능 |
| 얼굴·표정 인식 라이브러리 설치가 Jetson 환경을 깰 위험 (opencv-python 동반 설치) | 설치 전 의존성 확인, 수업 가이드(ir-guide) 방식 사용, `jetson_system_bridge.sh`로 복구 |
| 카메라 높이가 낮음 (와플파이 위) | 카메라를 올리는 거치대 사용 또는 올려다보는 구도 허용 |
| 사람이 많으면 와플파이 후진 공간 부족 | 후진 전 LiDAR로 뒤쪽 공간 확인, 시연 인원 3~5명으로 제한 |

## 10. 확장 아이디어

- 칠판 읽어주는 로봇과 통합: 사람을 찍으면 단체사진, 칠판을 찍으면 필기 기록 ("좋은 장면이 나오도록 로봇이 자리를 옮긴다"는 핵심이 같음)
- 구도 스타일 선택 (전신 / 상반신 / 셀카 느낌)
