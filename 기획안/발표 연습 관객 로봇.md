# 발표 연습 관객 로봇

> 발표 리허설 중 로봇 관객이 강의실을 돌아다님 → 발표자 시선이 청중 전체를 향하는지 채점

## 1. 개요

와플파이가 **청중석의 여러 위치로 이동하며 발표자를 촬영**하고, 발표자의 시선·몸 방향이 청중 쪽을 고르게 향하는지, 발표 시간을 지키는지 평가한다. 시간이 초과되면 발표자에게 다가가 알린다. 리허설이 끝나면 위치별 시선 점수와 개선점을 보고서로 보여준다.

- **실용성**: 발표 리허설을 혼자 할 때 객관적인 피드백을 받기 어려운 문제 해결
- **로봇이 필요한 이유**: 고정 카메라 한 대로는 "왼쪽 뒤 청중을 봤는가"를 알 수 없음 → 로봇이 **여러 청중 위치로 이동해 그 자리에서 본 시선**을 측정하는 것이 핵심
- **우리 팀도 사용 가능**: 12/3 Project Presentation 리허설에 직접 활용
- **수업 연결**: 좌표 변환(카메라 → 로봇 → 지도, 시선 방향을 지도 위 방향으로), 지도 기반 위치 추정·이동, 확률적 판정(시선 추정 노이즈)

## 2. 해결하려는 문제

- 발표할 때 한쪽만 보거나 화면(슬라이드)만 보는 습관을 스스로 알기 어렵다
- 혼자 리허설하면 시간 관리 피드백이 없다
- 친구에게 봐달라고 부탁해도 객관적인 수치는 얻기 어렵다

## 3. 시나리오

```
발표자가 리허설 시작 (발표 제한 시간 입력)
↓
로봇이 청중석 위치 A로 이동 → 발표자 얼굴·몸 방향 추정
↓
"이 위치를 향해 시선을 준 비율" 기록 → 일정 시간 후 위치 B, C로 이동
↓
발표 시간 체크 → 제한 시간 초과 시 발표자에게 다가가 알림
↓
리허설 종료 → 위치별 시선 점수 지도 + 시간 기록 + 개선점 보고서
```

## 4. 시스템 구성

| 모듈 | 입력 | 출력 | 사용 기술 |
|------|------|------|-----------|
| 지도 / 위치 추정 | LiDAR, 오도메트리 | 강의실 지도, 로봇 pose | SLAM, AMCL (0단계 결과 재사용) |
| 청중 위치 순회 | 지도, 청중석 지점 목록 | 목표 지점 이동 | 지도 기반 주행 (또는 정해진 지점 텔레옵) |
| 발표자 시선 추정 | 카메라 영상 | 얼굴·몸 방향 | 경량 얼굴 검출 + 얼굴 방향 추정 |
| 시선 점수 | 시선 방향, 로봇 위치 | 위치별 "바라봄" 비율 | 시선 방향이 로봇(청중 위치)을 향하는지 판정, 여러 프레임 누적 |
| 시간 관리 | 시작 시각, 제한 시간 | 초과 알림 | 타이머 + 발표자에게 접근 |
| 보고서 | 위치별 점수, 시간 | 결과 화면 | 지도 위 점수 시각화 |

## 5. 개발 단계

| 단계 | 목표 | 산출물 |
|------|------|--------|
| 0 | 로봇 연결, 텔레옵, 강의실(실습실) 지도 생성 | 지도 파일 |
| 1 | 고정 위치에서 발표자 얼굴 방향 추정 | 방향 추정 시각화 |
| 2 | "로봇을 보고 있는가" 판정 + 시선 점수 누적 | 한 위치 점수 |
| 3 | 여러 청중 위치 순회 + 위치별 점수 | 점수 지도 |
| 4 | 시간 관리 + 보고서 | 리허설 결과 보고서 |
| 5 | 안정화 / 평가 (팀 발표 리허설에 실제 사용) | 데모, 평가 결과 |

## 6. 평가 지표

- 시선 판정 정확도 (사람이 직접 라벨링한 영상과 비교)
- 위치 이동 효과: 고정 카메라 1대 vs 로봇 순회의 시선 분포 측정 차이
- 리허설 전/후 시선 균형 점수 변화 (피드백 효과)
- 처리 속도: FPS, 메모리 (`jtop`)

## 7. 데모 시나리오

1. 발표자가 슬라이드 앞에서 1~2분 발표 시작
2. 로봇이 청중석 왼쪽 → 가운데 → 오른쪽으로 이동하며 측정
3. 발표자가 일부러 오른쪽만 봄 → 결과 화면에 "왼쪽 청중 시선 부족" 표시
4. 제한 시간을 넘기면 로봇이 발표자 앞으로 다가와 알림

## 8. 필요 장비

- TurtleBot3 Waffle Pi (이동, LiDAR)
- 카메라: C920 / RealSense D455F / Pi 카메라 중 선택 (미정)
- 영상 처리: Jetson Xavier NX (로봇 탑재 여부 미정)
- 결과 표시용 노트북

## 9. 위험 요소 및 대응

| 위험 | 대응 |
|------|------|
| 거리가 멀면 얼굴 방향 추정이 부정확 | 줌이 되는 C920 사용, 시연 강의실 크기 제한, 얼굴 대신 몸 방향으로 판정 단순화 |
| Jetson 미탑재 시 영상 전송 지연 | 판정이 실시간일 필요 없음 → 정지 상태에서 측정, 사진/짧은 영상 단위 전송 |
| 얼굴 방향 모델 설치가 Jetson 환경을 깰 위험 (opencv-python 동반 설치) | 설치 전 의존성 확인, 수업 가이드(ir-guide) 방식 사용, `jetson_system_bridge.sh`로 복구 |
| 로봇이 이동하며 발표를 방해 | 이동은 정해진 통로로 천천히, 이동 중에는 측정 중단 |

## 10. 확장 아이디어

- 실제 청중이 있을 때 청중 반응(고개 숙임 등) 측정
